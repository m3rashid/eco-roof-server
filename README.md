## 📖 Overview

Backend for an eco-roofing business management system — manages operations, data, and workflows for an eco-roofing business.

## 🏗 Project structure

```
eco-roof-server/
├── main.py
├── config.py
├── app/
└── requirements.txt
```

## 🛠 Tech stack

`Python` · `Flask` · `SQLite`

## 📦 Quick start

```bash
git clone https://github.com/m3rashid/eco-roof-server.git
cd eco-roof-server
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
python main.py
```
